# DSA_WORDLE_Game
- This is the open ended DSA project from my 3rd semester. For this project, I wanted to make something new while also improving upon the OOP Monster Game that I coded the previous semester.
- Improves the modular design and optimizes a few things while simulating the WORDLE game in C++. This is also a Menu based Terminal Game.

# Tools
- C++

# Features

- Arrow key and Enter key based terminal game. **No mouse use is involved.**
- The player can select the type of audio they want to use as background music.
- Uses the Binary Search Tree for fast lookup and Circular Arrays for menu functionality based on arrow keys.
- The design is much more modular than the OOP Monster Game, on which this menu based system is modeled and expanded.
- Plays similarly to the popular WORDLE game online.

# Areas for Improvement
- The context is being modified upon each screen change through the use of recursion. At this stage, I had just learned about using stacks in the CPU to handle switching between different contexts, but I wasn't proficient enough nor did I have enough time, so the current design is basically Brute Force through recursion.
